# Clari API Backend Specification
# Generated: 2025-12-25
# Base URL: http://localhost:3000 (dev)

## 1. Overview
- Runtime: Bun
- Framework: Hono
- ORM: Prisma
- Database: PostgreSQL
- Base URL: http://localhost:3000
- Auth: JWT Bearer Token
- WebSocket: Native Bun WebSocket support

## 2. File & Route Structure
```
src/
  index.ts - Main app entry
  routes/
    auth.ts - Authentication (Google OAuth)
    note.ts - Note CRUD operations
    recording.ts - Recording session management + WebSocket
    stt.ts - Real-time STT WebSocket
    keywordpack.ts - Keyword pack management + AI features
    externalresource.ts - External resource scraping (Firecrawl)
  middleware/
    auth.ts - JWT authentication middleware
  utils/
    jwt.ts - Token generation/verification
prisma/
  schema.prisma - Database schema
```

## 3. Database Models

### User
```typescript
{
  id: string (UUID)
  email: string (unique)
  name: string?
  googleId: string? (unique)
  profileUrl: string?
  createdAt: DateTime
  updatedAt: DateTime
}
```

### Note
```typescript
{
  id: string (UUID)
  title: string
  content: string? (Text, contains transcript JSON)
  aiSummary: string? (Text)
  speakers: Json? (array of speaker objects)
  durationInSeconds: number
  isPublic: boolean
  recordingUrl: string?
  recordingStatus: "pending" | "recording" | "completed" | "failed"
  createdAt: DateTime
  updatedAt: DateTime
  lastUpdated: DateTime
  authorId: string
  keywordPackIds: string[] (array of IDs)
  externalResourceIds: string[] (array of IDs)
}
```

### KeywordPack
```typescript
{
  id: string (UUID)
  name: string
  keywords: Json (array of {name: string, description: string})
  createdAt: DateTime
  updatedAt: DateTime
  isPublic: boolean
  previewImageUrl: string?
  authorId: string
}
```

### ExternalResource
```typescript
{
  id: string (UUID)
  url: string
  displayUrl: string (URL without query params)
  title: string (max 10 chars)
  logoUrl: string?
  scrapedContent: string? (Text, markdown from Firecrawl)
  metadata: Json?
  createdAt: DateTime
  updatedAt: DateTime
  authorId: string
}
```

## 4. Common Types & Patterns

### Authentication Header
```
Authorization: Bearer <JWT_TOKEN>
```

### Error Response Format
```json
{
  "error": "Error message"
}
```

### Pagination (Query params)
```
?limit=20 (default: 10-50 depending on endpoint)
?sort=recent_used|recent_created (for notes)
```

## 5. API Routes

### [routes/auth.ts] - /auth/*

#### POST /auth/google
- Auth: Public
- Description: Google OAuth login/signup
- Request:
```json
{
  "idToken": "google_id_token_from_oauth"
}
```
- Response (200):
```json
{
  "accessToken": "jwt_token",
  "user": {
    "id": "uuid",
    "email": "user@example.com",
    "name": "John Doe",
    "profileUrl": "https://..."
  }
}
```
- Errors:
  - 400: `idToken is required` | `Email not provided by Google`
  - 401: `Invalid token`
  - 500: `Authentication failed`

### [routes/note.ts] - /notes/*

#### GET /notes
- Auth: Protected (Bearer token)
- Description: List user's notes
- Query Params:
  - `limit` (optional, default: 10): Number of notes
  - `sort` (optional, default: recent_used): `recent_used` | `recent_created`
- Response (200):
```json
{
  "notes": [
    {
      "id": "uuid",
      "title": "Meeting Notes",
      "durationInSeconds": 3600,
      "createdAt": "2025-12-25T10:00:00Z",
      "updatedAt": "2025-12-25T11:00:00Z",
      "lastUpdated": "2025-12-25T11:00:00Z"
    }
  ]
}
```

#### GET /notes/:id
- Auth: Protected (Bearer token)
- Description: Get single note details
- Path Params: `id` (note UUID)
- Response (200):
```json
{
  "note": {
    "id": "uuid",
    "title": "Meeting Notes",
    "content": "{...}", // JSON string with transcript
    "aiSummary": "Summary text",
    "speakers": [
      {"speaker_id": "0", "speaker_name": "참석자 1"}
    ],
    "durationInSeconds": 3600,
    "isPublic": false,
    "recordingUrl": "https://...",
    "recordingStatus": "completed",
    "createdAt": "2025-12-25T10:00:00Z",
    "updatedAt": "2025-12-25T11:00:00Z",
    "lastUpdated": "2025-12-25T11:00:00Z",
    "authorId": "uuid",
    "keywordPackIds": ["uuid1", "uuid2"],
    "externalResourceIds": ["uuid1"]
  }
}
```
- Errors:
  - 404: `Note not found`
  - 403: `Access denied` (not owner and not public)

#### PATCH /notes/:id
- Auth: Protected (Bearer token)
- Description: Update note title or speakers
- Path Params: `id` (note UUID)
- Request:
```json
{
  "title": "Updated Title (optional)",
  "speakers": [
    {"speaker_id": "0", "speaker_name": "Custom Name"}
  ] // optional
}
```
- Response (200):
```json
{
  "note": { /* full note object */ }
}
```
- Errors:
  - 404: `Note not found`

#### DELETE /notes/:id
- Auth: Protected (Bearer token)
- Description: Delete note
- Path Params: `id` (note UUID)
- Response (200):
```json
{
  "message": "Note deleted successfully"
}
```
- Errors:
  - 404: `Note not found`

## 6. Business Flows

### Authentication Flow
```
1. User initiates Google OAuth (frontend)
2. Frontend gets idToken from Google
3. POST /auth/google with idToken
4. Backend verifies token, creates/updates user
5. Backend returns JWT accessToken
6. Client stores accessToken
7. Use accessToken in Authorization header for all protected routes
```

### Recording Session Flow
```
1. Create session: POST /notes/session
   → Returns sessionId
   
2. Connect WebSocket: ws://.../notes/session/:sessionId?token=jwt
   → Receive "ready" message
   
3. Send audio chunks: {"audio": "base64..."}
   → Receive real-time transcripts (partial, committed, formatted)
   → Receive keyword detections (if keywordPackIds provided)
   → Receive resource hints (if externalResourceIds provided)
   
4. Toggle features during recording:
   - {"action": "keyword.control", "data": "off"}
   - {"action": "hints.control", "data": "on"}
   
5. Stop recording: POST /notes/session/stop
   → Returns full transcript, speakers, recording URL
   
6. Or cancel: POST /notes/session/cancel
   → Deletes note immediately
```

### Note Management Flow
```
1. List notes: GET /notes?limit=20&sort=recent_used
2. View details: GET /notes/:id
3. Update: PATCH /notes/:id (title, speakers)
4. Delete: DELETE /notes/:id
```

### Keyword Pack Flow
```
1. Create pack: POST /keywordpacks {"name": "AWS Terms"}
2. Add keywords manually: POST /keywordpacks/:id/keywords
3. OR use AI autocomplete:
   - POST /keywordpacks/ai/autocomplete {"name": "Lambda"}
   - Select from 5 suggestions
   - Add to pack
4. OR use AI autofill:
   - POST /keywordpacks/ai/autofill {"query": "AWS terms", "count": 50}
   - Get 50 keywords at once
   - PATCH /keywordpacks/:id with full keywords array
5. Use in recording: POST /notes/session {"keywordPackIds": ["uuid1", "uuid2"]}
```

### External Resource Flow
```
1. Scrape website: POST /externalresources {"url": "https://..."}
   → Firecrawl scrapes content
   → GPT generates 10-char title
   → Returns resource with scraped content
2. List resources: GET /externalresources
3. Update title: PATCH /externalresources/:id {"title": "New Title"}
4. Use in recording: POST /notes/session {"externalResourceIds": ["uuid1"]}
   → During recording, hints appear when related words detected
5. Delete: DELETE /externalresources/:id
```

## 7. WebSocket Audio Format

### For Recording & STT WebSockets
- Format: PCM (Raw audio)
- Sample Rate: 16000 Hz
- Encoding: Signed 16-bit
- Channels: Mono (1)
- Transmission: Base64-encoded JSON

**Client Audio Capture:**
```
Record audio → Convert to PCM 16kHz mono → Base64 encode → Send as JSON
```

**Example (pseudo-code):**
```kotlin
// Android MediaRecorder setup
val audioFormat = AudioFormat.Builder()
    .setEncoding(AudioFormat.ENCODING_PCM_16BIT)
    .setSampleRate(16000)
    .setChannelMask(AudioFormat.CHANNEL_IN_MONO)
    .build()

// Send chunks
val base64Audio = Base64.encodeToString(audioBytes, Base64.NO_WRAP)
websocket.send("""{"audio":"$base64Audio"}""")
```

## 10. Notes for Android Integration

### Retrofit Setup
- Base URL: `http://10.0.2.2:3000` (Android emulator) or actual server URL
- Add Authorization interceptor for Bearer token
- Use OkHttp for WebSocket connections

### WebSocket Libraries
- Use OkHttp WebSocket for recording sessions
- Handle JSON serialization with Gson/Moshi
- Manage connection state (ready, recording, closed)

### Audio Recording
- Use MediaRecorder or AudioRecord
- PCM format: 16000 Hz, 16-bit, mono
- Chunk size: 1024-4096 bytes recommended
- Base64 encode before sending

### State Management
- Store JWT token securely (EncryptedSharedPreferences)
- Handle session lifecycle (create → connect → record → stop)
- Display real-time transcripts using LiveData/Flow
- Show keyword/hint cards as they arrive

### Recommended Architecture
```
UI Layer (Compose/Views)
  ↓
ViewModel (State management)
  ↓
Repository (API + WebSocket)
  ↓
Data Layer (Retrofit + OkHttp)
```
